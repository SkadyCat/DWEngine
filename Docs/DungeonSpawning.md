# 地牢整批出怪

开始挑战时，按当前地图数量一次性发布全部小怪与一个首领，不再使用三波小怪和后置首领。击败首领立即通关，小怪不作为通关条件。沿用当前的手动开始、重置开局、地图数量公式和 300 只上限。默认 T1 为 19 只小怪和 1 个首领，默认基础数量下 T10 为 190 只小怪和 1 个首领。

资产异步加载，隐藏 Actor、原生规则注册和血条仍逐帧准备；准备期间角色与规则时钟冻结。全部准备完成后在同一帧显示并启用。这个阶段不会逐个放怪进战斗。首领仍使用原有生命、技能、模型和掉落规则。

击败首领时结算一次通关与首层任务，不要求清完小怪；先清小怪而首领存活则不通关。关闭结算弹窗后仍可继续战斗、清理小怪和拾取掉落，不会重复结算。宝库等奇遇交互触发的守卫继续沿用各自流程。

`EDWOTowerPhase::Waves`、`EDWOTowerCommand::Wave` 和值为 1 的 `Run.Wave` 保留为已有接口兼容标记，已不再推进波次。显式 `Boss` 命令仅为原有首领、掉落和血条验证入口保留，正常挑战流程不会再发出它。

验证入口：`Tools/Verify-FrameSpreading.ps1` 检查 20 / 300 只及重试时整批发布、仅一个首领、每只的原生规则池和暂停保护；`Tools/Verify-Dungeon.ps1` 检查真实地牢导航、全部出怪、战斗掉落与换层；`Tools/Verify-BossClear.ps1` 检查首领先死亡立即通关、保留小怪、真实结算按钮与继续战斗，以及死亡、倒计时和不重复结算。
