# 地图奇遇：打宝、选装与装备制作

第一版包含百炼法坛、封印宝库、遗珍神龛和万相合成祭坛。事件由地图自己的随机流选择和放置，不消耗战斗或普通掉落随机流。事件提供额外奖励入口，装备生成与通货效果继续调用现有 DWRulesCore；不调整原有基础掉率、装备数值或通货规则。

## 百炼法坛

交互打开 UICreator 原生界面，从背包放入一件已鉴定且未装备的装备，确认后锁定该 UID。本张地图的该法坛只加工这一件装备，不能换入其它装备。显示当前法坛唯一提供的通货效果、装备完整词条、可选洗炼行、制作次数及每次结果。

无限次数表示无限免费调用该通货的既有效果，没有次数上限，也不会把通货发进背包。下品灵石仍按原规则绑定第一条洗炼词条；陨星石仍按原规则作用于整件装备。制作失败不改变装备、背包通货或随机流。

锁定期间不能装备、出售、丢弃、重复放入另一法坛、在普通制作页改造或导入覆盖背包。关闭界面不会换掉锁定对象，回到本坛可继续制作。点击“收取装备”解除锁定并结束本坛；离开地图时解除本图锁定，保留已经制作完成的装备结果。装备始终保有原 UID，不复制出第二件。

## 封印宝库

击败本图首领后，靠近宝库按 V 交互，开启守库者挑战。守库者全部死亡后开启奖励，展示三件按本图 T 阶生成的稀有装备，选择一件领取。选装备前能看到实际词条；打开或关闭不会重抽；领取只会成功一次。

## 遗珍神龛

击败本图首领后解封，提供三件随机传奇候选，选一件。当前界面契约为三选一。所有候选由现有传奇生成规则生成，含固定传奇词条与真实随机词条，不使用展示占位装备。

## 万相合成祭坛

按 V 打开界面，放入两件已鉴定且未穿戴的同部位装备，左件决定底材、部位、技能和 T 阶。确认锁定后，点击“开始合成（消耗两件）”，原子地消耗两件并生成一件新装备。

左、右两侧分别均匀随机抽取 0～该侧全部词条，并在该侧无放回抽取。随机词条和固定传奇词条都参加；底材基础属性不参与抽取。继承词条保留来源的数值和词条阶级，即使右件词条高于新装备 T 阶，也不重新缩放。结果允许多个传奇词条，同名效果的生效/叠加仍由既有规则引擎决定。两侧都抽到零条时得到保留左件底材的无附加词条装备。

没有可取消的随机预览：抽取、消费、发放在同一操作中提交，失败不消费材料，也不推进事件随机流。后续普通制作保留多传奇词条；存档使用兼容的 synthesized / extraLegendary 实例字段，旧存档格式与普通掉落不变。

## 地图生命周期与交互

默认 75% 的地图出现奇遇，出现时为 1–2 个不同类型，优先放在导航可达且彼此分开的探索点。奇遇概率、权重、守卫数量、候选数和领取数独立于规则目录，数据源为 `Content/MapEvents/events.json`。地图准备阶段冻结配置、候选装备 ID 和奖励 T 阶，途中切换地图核心不会抬高已生成奇遇的奖励阶级；每次地图重建创建新的事件实例。已经完成的事件不会因重复点击或关开界面再次发奖。

UI 在 UICreator 独立源工程制作，使用单独的 UE 导出目录，保持现有 HUD 和装备说明控件的所有权。AS 管理事件状态、输入与交互流程，原生适配层负责装备原子提交、实际物品锁、资源和 HTTP 数据边界。

## 后续可复用的玩法

- 猎宝悬赏：选定一个装备槽位，击杀地图里的标记精英后获得该槽位候选，帮助补齐缺装。
- 弃宝换珍：提交一件已有装备，换取本图 T 阶的候选；确认界面明确显示代价后再消耗。
- 连战宝匣：每轮击杀后选择结算或继续，后续轮次增加装备候选或领取数；不直接改动装备数值。
- 预兆祭坛：向同一件装备提供指定预兆的制作服务，沿用原词条家族与冲突规则。

后续玩法仅作为设计方向，首版实际接入范围为上述四类事件。

## 源文件与验证

UICreator 源工程：`UIAuthoring/MapEvents.uialpha.json`，工程 ID `opus-map-events`。生成脚本 `Tools/UI/Author-MapEvents.mjs`；UE 原生资源目录 `/Game/UICreatorEvents`。

`Tools/Verify-MapEvents.ps1` 通过导出的真实按钮进行放入、锁定、反复制作、合成、三选一，并在原生战斗中击杀六名守库者。`-Preview -View fusion|fusion-result|altar|reward` 渲染对应 UE 界面。原生自动化 `Opus.MapEvents.ItemTransactions` 验证多传奇继承、原子消费、120 次免费制作、零词条结果、重复领取防护和存档往返。

验证资料位于 `Saved/Verification/MapEvents` 和 `Saved/Verification/MapEventsUICreator`。UICreator 最终导出包为 `wbp-events-78c619bf-a789-48a1-98ec-459e75ccbf34`，55 个逻辑控件、9 个原生按钮、98 个 PNG 缓存；独立重载与五档响应式布局误差均为 0。浏览器参考图与 UE 原生图的逐像素检查中，没有通道误差超过 8 的像素，约 99.49% 像素完全一致。

场景里的宝库和祭坛目前使用可交互的几何占位模型；守库者沿用现有 Zero 谱系角色及战斗表现。按 V 交互，Esc 关闭。锁定后的制作列表复用控件，连续制作不会每次重新创建整套界面。

最终验收：`Saved/Verification/MapEvents/final-verification.json`。实际按钮全流程、六名守卫原生战斗、换核心不抬高奇遇奖励 T 阶、关闭不重抽、装备存档回读，以及网站地图池回归均通过。实拍为 `preview-fusion-result.png`（同件装备上两种不同传奇词条）和 `preview-altar.png`（锁定后无限通货界面）。
