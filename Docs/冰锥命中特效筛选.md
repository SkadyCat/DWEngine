# 冰锥命中特效筛选 · 2026-10-25

来源：`CustomTools/特效`，保留原 Niagara 内容。原生资产注册表共找到 8 个不同的冰系 hit 候选，另有白色、绿色配色变体；完整路径、启用的发射器和依赖见 `CustomTools/特效/Docs/IceHitCandidates.json`。

| 资源 | 启用发射器数 | 本轮判断 |
| --- | ---: | --- |
| IceSkill_VFX / NS_Ice_Hit_Small | 6 | 选用。短促碎冰，较少遮住目标，适合连续单体命中 |
| Super_Pack_Spells / NS_Ice_Spells_Hit1 | 4 | 雪花散开，范围比 Small 松散，可留作备选 |
| Super_Pack_Spells / NS_Ice_Spells_Hit2 | 5 | 更明显的雪花扩散，不作为这次普通冰锥 hit |
| Super_Pack_Spells / NS_Ice_Spells_Hit3 | 7 | 冰刺加雪花，轮廓更重，适合强化命中候选 |
| StatusVFX / NS_StatusVFX_Ice_Hit | 4 | 带 SkelMesh 参数，需角色网格采样接线，本轮不选 |
| StatusVFX / NS_StatusVFX_Frost_Hit | 5 | 带 SkelMesh、Snow_SpawnAmount 参数，本轮不选 |
| MagicProjectiles / NS_Ice_Impact | 5 | 带 Scale 参数；未调作者参数，本轮不以独立靶子的空画面判断效果 |
| MagicProjectiles_Optimal / NS_Ice_Impact | 4 | 同上，保留为后续候选 |

发射器数量用于识别资源，不能单独代表 GPU 性能。对比预览使用 0.5 缩放与 180cm 靶子，Small 的 0.08 秒与 0.25 秒画面对比确认其短促性。原 `NS_Ice_Explosion_Spear` 为 8 个启用发射器，具有更明显的地面爆炸轮廓。

最终只替换 `/Game/WebVFX/DA_UEVFXMap` 的 `ice_lance.impact`：Small，缩放 0.5，零偏移，不跟随来源，最长 1 秒回收。飞行资源、预算和其余映射项经读回比较保留。

Small 的原生依赖闭包有 14 个资产，13 个已经存在，新增的系统约 4.5 MB；全部按源文件 SHA-256 校验。规则实现和规则数据均未修改。

实机验证使用现有 `-DWOHeroArena -DWOTransient -DWOUEVFXTest` 空场，避开当前地牢场景对旧世界原点靶子的遮挡。首次运行有 Niagara 编译未完成时的默认回退，因此正式验收增加仅测试生效的 `-DWOUEVFXWarmup=5`。它不会改变普通开局。
