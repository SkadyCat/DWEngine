# 投射物重新索敌与近距离制导

用户确认：重新索敌保留原发射位置，不传送投射物、不重新套用「从目标周围向中心发射」。本次仅修改 Studio 与 UE 已有投射物飞行实现，装备词条数值、索敌次数、死亡后追踪条件、伤害、碰撞半径和寿命不变。

旧实现全速追逐目标位置，转弯半径约为 `速度 / 角速度`。目标处于转弯圆内时，投射物会绕圈；穿透后还会继续锁定命中过、碰撞系统已排除的目标。

新实现保持原转向速度上限，只有在当前方向尚不能扫中目标时，按目标距离与剩余角差临时减速，让目标视线的旋转速度低于可用转向速度。对准后恢复飞行速度；穿透等速度修正继续保留。分裂复制使用减速前速度，避免将一次急转弯的临时减速永久带给子弹。

重新锁定时过滤该投射物完整命中记录（含溢出集合）；目标已命中或离开追踪范围时释放锁定，按剩余索敌次数寻找有效目标。找到目标才扣次数，不改变当前位置、发射原点或剩余寿命。实际伤害仍由原来的连续碰撞扫描结算。

验证：`CustomTools/RuleStudio/tests/projectile-homing.test.mjs` 覆盖 30/60/120 FPS、侧面/背后近距离目标、移动目标、穿透后重新锁定、索敌次数、原点和寿命不变、转速上限及速度恢复。与召唤物和敌方眼球追踪回归合计 31 项通过。

`myriad-swords.test.mjs` 现有 3 项失败与本次修改无关：旧测试仍要求 T10、33 枚首批与旧三波结构。修改前逻辑通过只读模块加载器在内存回放，修改前后均为同样 3 项失败、8 项通过；当前 T1 万剑固定词条、30 枚首批、汇聚发射和真实伤害检查通过。证据保留于 `Saved/Verification/ProjectileHoming/myriad-before.log`、`myriad-after.log`。
