# 嘲讽 / Taunt

手动主动技能 `taunt`。角色固定装备授予装配资格；在技能槽选择“嘲讽”，切换到该槽后左键或空格释放。无需瞄准敌人。状态持续 2 秒，释放成功开始 10 秒独立冷却，期间可以换用其他技能。切槽、卸下或重新装配不会重置这次冷却；暂停冻结规则时间。

配置同时位于 `Content/Rules` 和 `Content/RulesTower`，数值由相同 JSON 提供。网页技能集合为 `Content/Rules/WebBuilds/taunt.json`，UE 原生集合为 `Content/RulesTower/Builds/taunt.json`；特性与状态保持同名镜像。

| 组合项 | ID | 职责 |
| --- | --- | --- |
| 施加自身状态 | `create_taunt` | 既有 `apply_status`，`origin:owner`，持续 2 秒 |
| 自身施法 | `self_targeted_cast` | 允许不锁定敌人释放 |
| 独立技能冷却 | `independent_skill_cooldown` | 聚合 10 秒冷却，以技能 ID 保存，其他技能继续可用 |
| 状态携带的牵引 | `hostile_projectile_attraction` | 每个模拟步转向施法者，覆盖旧弹和新弹，仅敌对阵营 |
| 状态携带的无敌 | `damage_immunity` | 拒绝命中和持续受伤，护盾与生命不扣除，晕眩不累积 |

`Statuses/taunt.json` 使用既有状态携带特性机制授予后两项。状态到期后自动移除；角色死亡时停止吸引。牵引只改朝向，保留速度、竖向运动、阵营、所有者、伤害、生命周期和正常碰撞，仍会被地形阻挡。友军与玩家自己的投射物不变。

UE 的目标选择、弹道转向和独立冷却由 `Script/Opus/SelfSkills.as` 执行。C++ `OpusDeliveryPolicy` 只提供通用的串行运动回调、受伤许可回调、状态特性快照和速度写入适配。回调挂在既有战斗宿主扩展中，未绑定时保持原行为；VM、伤害公式、状态解释与碰撞流程不变。新增 Sheet 目录项并补齐 Build/Status 对原生纯 Sheet 特性的目录兼容校验，仍拒绝直接引用网页动作特性。

四个能力特性均不进入随机装备词条池，避免随机装备获得常驻无敌。网页 `public/sim/self-skills.mjs` 为同一配置的战斗原型适配。

验证入口：网页 `node --test tests/taunt.test.mjs tests/stun-crust.test.mjs`；UE `Tools/Verify-Taunt.ps1 -Visuals`。UE 使用临时存档，并测试实际动画释放通知、既有/新生/友军投射物、状态边界、命中与 DOT、切槽、重新装配、暂停和冷却后再次释放。
