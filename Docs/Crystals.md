# 无效结晶与祈愿结晶

| 通货 | ID | 效果 |
| --- | --- | --- |
| 无效结晶 | `annulment_crystal` | 均匀随机移除一条随机词缀，保留其他词缀原值 |
| 祈愿结晶 | `wish_crystal` | 从既有可用词缀池随机增加一条不冲突词缀，数值词缀在 T1 至装备 T 阶抽取 |

两者都是稀有通货、堆叠 99，每次消耗一个；保留实例 UID、装备品质、底材、技能、基础属性和固定传奇，包括合成装备的额外传奇。未鉴定或固定系统槽装备不能加工。空词缀装备不能使用无效结晶；没有可用词缀时祈愿结晶失败。失败不扣材料、不改装备，也不推进原生制作随机流。

无效结晶不搭配预兆。若删去未绑定洗炼的词缀，只修正剩余绑定索引；若删去某一品级已绑定的词缀，该品级和后续品级的绑定失效，先前品级保留，避免幸存词缀被悄悄换到另一个通货品级。祈愿结晶保留洗炼绑定，并沿用预兆对新增词缀族的限制。

原生通货配置同时位于 `Content/Rules/Items` 与 `Content/RulesTower/Items`。UE 使用原有原生制作事务和 UICreator 装备详情：固定详情后激活通货，再点击“随机移除 1 条词缀”或“随机增加 1 条词缀”。网页独立制作和 Studio3D 装备详情共用网页制作事务。UE 不加载网页 JS。

默认地图候选池及商店从通货目录读取，已接入新 ID；没有给正式存档额外发材料。新图标由全项目缺图补齐任务统一制作与登记，本任务不覆盖既有图标。

验证：`Tools/Verify-Crystals.ps1` 运行 `DWO.Crafting.Crystals`，覆盖原生增删、扣费、失败回滚、洗炼绑定、存档重读、装备状态刷新和详情制作资格，再实际请求后端地图掉落目录。记录在 `Saved/Verification/Crystals/receipt.json`。网页新增测试位于 `CustomTools/RuleStudio/tests/crystals.test.mjs`，并已回归灵石品级、陨星石与部位词缀池。
