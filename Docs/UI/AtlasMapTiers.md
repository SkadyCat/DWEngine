# 世界地图层级来源

地图物品定义中的 `tier` 决定本次挑战层级，支持 T1–T16。星图距离只决定空间位置与路线，不再生成层级或要求地图票匹配距离。未放图且没有入场记录的区域显示“层级由放入的地图决定”。初始界域无图时保留免费 T1 入口；主动放图时按该地图进入并消耗一次。

Studio 的详情、悬停、地域列表、实际战斗、守卫名称、HUD 与掉落上限共用入场层级。地图核心继续提供原有词条，装备掉落最高 T10 的规则保留。修改核心不会重置已入场地图的掉落层级。

网页存档新增 `mapTiers`，UE 星图文本新增 `map-tier` 记录；均兼容原存档并保留探索路线。地图消耗、失败、重载后保留实际入场层级；装配下一张地图不会改变正在进行的战斗。

验证证据：`Saved/Verification/AtlasMapTiers`。27 项网页测试通过，包含真实 T3 战斗、守卫、HUD 与掉落上限检查；UE 的 `Verify-MapDevice.ps1` 集成、独立重载及渲染检查通过，并检查 T16 入场和下一张地图预览互不干扰。UI 继续复用 UICreator 控件与绑定，规则引擎和既有词条数值未修改。
