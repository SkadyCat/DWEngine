# 祭坛：左背包、右操作区

按参考图将装备背包独立放在左侧，祭坛放在右侧。作者画布为 1280 × 660，左侧背包 620 × 330，距顶部 76；右侧祭坛从 x=640 开始。背包仍为 8 列、3 行，支持分页。

## 来源与实现

- Studio3D 的 UICreator 项目：`opus-studio3d-map-events`。
- 作者脚本：`CustomTools/RuleStudio/scripts/author-map-events.mjs`。
- 共享控件：`equipment-cell.js` 直接实例化已有 `battle-prefab-item-cell`，保留背包的品质四态、图标裁剪和标记；没有再画另一套装备格。
- 网页控制器：`CustomTools/RuleStudio/public/battle-map-events.mjs`。
- 原生作者入口：`Tools/UI/Author-MapEvents.mjs`，通过 `MapEventCraftUI.mjs` 消费同一份 Studio3D 作者源。
- UE 接入：`Script/Opus/MapEventCraftUI.as`。祭坛事务仍由既有 `MapEvents.as` 和原生规则接口执行。

网页原来的拖拽先后冲突：物品详情组件会先将拖拽标为 active，而后面的移动处理只在 `!active` 时创建拖拽提示，快速移动会跳过创建。现在在捕获阶段处理移动，图标提示可重复检查创建，使用实际 UICreator 图标控件跟随指针；放入槽会高亮。关闭、失焦、取消或松开均清理拖拽状态。

支持背包拖入装备槽、未锁定投入装备拖回背包；通货槽不接收装备，锁定后不能移动。UE 读取实际 UButton 的按住状态和释放事件，不依赖可能被 UMG 消费的 PlayerInput 鼠标按键状态。

本次还修正空格残留的 T 阶底色、长装备名的换行挤压、法坛通货不在随机商店库存时的图标/名称缺失。原生场景遮罩也由 UICreator 提供；网页背景额外使用 CSS 模糊，原生此处使用遮暗。
