# Studio 世界地图入场按钮

已更新本机 `http://127.0.0.1:5291/?view=battle`，并通过实际首页加载及世界地图交互验收。

- 付费区域没有有效地图时，按钮禁用，点击不能触发入场。
- 放入有效且拥有的地图、所选区域允许进入时，按钮启用，边缘播放 UICreator 激活流光。
- 取下地图或选择不可达区域后，立即停止流光并禁用按钮。
- 起始免费地图和当前战场返回保留既有规则，不播放装配激活流光。
- 删除区域状态、相连地域及已发现地域下拉框。
- 使用 UICreator 四态皮肤；键盘焦点使用柔和反馈。

控件工程为 `studio-atlas-entry`，源文件 `UIAuthoring/AtlasEntry.uialpha.json`。实际入场仍由既有地图票与区域条件控制。

`Saved/Verification/MapEntry/web-receipt.json` 记录真实鼠标操作、装入/取下及动画跨帧推进检查；`studio-receipt.json` 记录 5291 正式页面加载新版本、显示新控件且没有脚本异常的验收。测试使用独立浏览器配置，不修改用户浏览器存档。

同轮修复了导出器在默认禁用时丢失正常皮肤的转换缺口：四态独立导出，启用态能够恢复自己的皮肤。
