DungeonWorld Opus 迁移验收

工程位置：G:\DungeonWorldOpus
启动：双击 Start-RuleTower.cmd；重新编译执行 Build-Opus.ps1。
默认第 1 层、T1 霜棘法杖、单技能、准备状态；回车或设置页按钮开始。
本任务仅读取 Beta，没有向 Beta 写入文件。

运行结构
业务与爬塔流程为 AngelScript，Lua 提供原生调用入口。保留 C++ DWRules 规则引擎；C++ 游戏模块只做原生互操作、数据查询、文件与显示。工程没有 JS/MJS/CJS 运行逻辑，不依赖 Node、浏览器、Vue 或 Puerts。PowerShell/Python 仅用于构建、验证和离线资产重建。

规则与兼容
1047 份规则 JSON 哈希均保持迁移快照原值。按你允许的范围修复原生兼容：控制单位上限、装备授予技能、献祭、元数据、分层中毒、召唤投射物连续发射及衍生伤害归属。另修复 AS 初始化早于组件 BeginPlay 时的目标编号绑定，避免角色与规则血量脱节。规则公式和数值未重新设计。文件与原始/当前哈希见 Docs/NativeCompatibility.json。

爬塔与 SVG
三波普通怪加守卫、20–300 怪总量、1–100 层、可选 30 秒限时、跨层资源继承、死亡重试、背包存档已接通。使用 Beta/Zero 谱系模型及现有兼容动画。接入当前 SVG 导出的 2665 节点、43 状态原生 WBP；爬塔所需的背包、装备、技能、构筑、打造、商店、通关商人、过滤与设置由 AS 处理。结算继续按钮挑战下一层，死亡重试返回准备状态。
不迁入原项目的其他 UI；网页编辑器、异界探索和调价工具不作为本次爬塔入口。

近期 session 研究与特效
复用最近 SVG 原生化成果；Web 特效已恢复并执行原生重建管线：51 几何、28 材质、100 帧数据剪辑、40 公开预制体。运行由原生 DWRules 表现层驱动，没有逐帧执行 JS。导入回执 pending=0，原生资产已保存；实机战斗截图可见 Zero 怪物与特效。详情见 Docs/RecentSessionResearch.json 与 Tools/WebVFX。
