# 最近玩法接入 UE

目标工程为 `G:/DungeonWorldOpus`。以最近用户确认及当前规则数据为依据；聊天中的“完成”报告只作为复核线索。原始需求摘录和会话来源保存在 [Requirements.json](Requirements.json)。

游戏运行时采用已有原生 DWRules、Lua 和 AngelScript。新增兼容能力继续使用同一规则编译、聚合、事件、投射物和碰撞链路。离线 UICreator/VFX 工具可以使用 JavaScript，游戏不加载或执行这些工具。

|---|---|---|
| 旋风 | 真实投射物，27米/秒、8秒，定时随机转向，墙体及活动半径折返 | 同一目标可按间隔重击；多重、返回和命中预算保持聚合 |
| 五种地面 | 燃烧、冰缓、感电、毒性、镜像；真实命中创建，独立持续时间和范围 | 高速扫掠与高度过滤；接触、染色分别启用；染色不改伤害元素 |
| 镜像 | 离开后再进入才复制；副本继承剩余寿命与词条并独立计命中 | 不在出生重叠时递归复制；可继续穿越其他镜像地面 |
| 回响 | 自身5秒状态，下一个手动非回响技能完整复施一次，CD5秒 | 消耗真实状态；不追加支付，不算手动输入，不递归 |

## 当前可复核成果

- 五个项目模块已通过正式UBT编译，包括DWRules；没有重编引擎。
- 完整规则目录及27个预设通过原生冷加载，1222份规则已同步到RulesTower。重复的旧嘲讽定义经内容对比后归档，保留规范定义。
- 六项原生机制测试通过：回响、宝库叠层与泊松出射、镜像、捕获、魔力封印、天地乖离剑。覆盖真实飞弹、碰撞、独立CD、零额外支付、层数倍率和装备点伤。
- UICreator `opus-recent-gameplay` 为9模板、185节点、443张透明贴图、按钮四态。导入、保存、独立进程重载及动态按钮交互通过；2400×1800原生画布与冻结参考逐像素测量通过，不做对齐、缩放或遮罩，整体RGB平均绝对误差为0.00540/255。
- VFX为58个公开项、186个含变体项、158种网格、70种材质，保留56个原始来源指纹。二进制及全部70个生产着色器动态分支DXC检查通过；UE冷读匹配全部动画载荷及引用，70个材质实际完成编译，无默认材质替代。旋风、法阵、终结技、临时眼球经实际游戏链路验证并截图。
- 藏身处使用原始场景几何转换后的原生资源；仓库、商品、任务候选保存完整装备实例。游戏不加载网页工厂。
- 原生交互验证覆盖：50%及100%封印、关闭不回蓝、卸装失效、三选一按钮领取、禁止重抽及重复领取、完整装备UID/数量往返、96个格子拖放处理器、按位置保存仓库和本地商品、切换藏身处后取回。
- 天赋、嘲讽及玩家受击/硬直回归通过。100个传奇全部支持；天赋分配与跨场景恢复通过。普通游戏已恢复到手动准备状态；临时测试的奖励、装备和仓储没有写入正式存档。

可复核汇总见 [Verification.json](Verification.json)，包含每项日志指纹、规则数据一致性、像素误差及资源计数。原始日志保存在 `Saved/Verification/UEIntegration`。

## 使用入口

- `O`：装配由当前非武器装备授予的光环；`Q/E/F/G`：开启或关闭相应槽。主动技能仍使用`1–4`。
- `J`：首层任务；首层首领击败后出现三件已保存的候选。
- `H`：准备或挑战结束时进入/离开藏身处。仓库与“我的商品”支持点击和跨区域拖放；Shift点击存放1个。
- 预制BD可选择旋风、回响、王之宝库等已有配置。王之宝库武器授予天地乖离剑，2号槽选中后点击目标位置释放，需有实际宝库层数。

商家商品沿用源页面的本地上架/下架模型。本轮不新增外部交易服务。实战特效截图使用隔离关卡中的无敌靶稳定取景，伤害、碰撞与倍率另由原生自动化检验。

## 验证入口

```powershell
node Tools/WebVFX/export-prefabs.mjs
node Tools/WebVFX/check-export.mjs
powershell -File Tools/Verify-ContentIntegration.ps1
powershell -File Tools/Integration/Run-Stage.ps1 -Stage NativeTests
powershell -File Tools/Integration/Run-Stage.ps1 -Stage RecentHost
powershell -File Tools/Integration/Run-Stage.ps1 -Stage ModernCombat
powershell -File Tools/Integration/Run-Stage.ps1 -Stage VFXCold
python Tools/UI/Measure-RecentUICreator.py
python Tools/Integration/Verify-Delivered.py
```

规则全目录冷加载由 `Script/Opus/ContentIntegrationTests.as` 执行，并逐个应用当前预设。测试使用 `-DWOTransient`，不得写入正式玩家存档。

VFX中间文件只保存在 `Saved/WebVFX/Source`。UE使用保存的DataAsset、StaticMesh、材质和贴图，不在游戏中导入OBJ/GLSL。`Tools/WebVFX/Rebuild.py` 必须在非PIE编辑器命令进程内执行，之后需要另一个冷进程检查保存结果和真实游戏显示。

当前工程多个专项任务共用同一工作目录。编译和UE验证需先协调窗口；不覆盖地图、奇遇、天赋、HUD及嘲讽专项的代码和验收证据。本任务证据独立保存在 `Saved/Verification/UEIntegration`。

原生构建入口为 `Tools/Integration/Build-Native.ps1`，仅构建五个项目模块，包含共享ABI的DWRules。Lua/AS日常修改不需要重编引擎。
