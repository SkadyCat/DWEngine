# 怪物装备外观

本次范围为 3C 实验场的装备外观和挂点。100 个单位使用 95 个外部部件，19 个单位保留模型中已有的弓、弩或法书。装备不参与训练伤害、属性或碰撞判定。

复用 Beta 的武器模型和材质，校验完整的 43 个包依赖；新增拷贝 27 个原始资源文件，SHA256 记录在 `equipment-migration.json`。角色原网格、骨架和动画未被重写。

握持姿势参考原配套武器挂点，并用手腕、食指和中指骨确定手掌坐标系。运行时锚定手骨，避免原独立武器骨在部分攻击、死亡片段里偏离手掌。短剑、重斧、盾牌和部分长武器根据体型缩放；缩放围绕握持点进行。`Config/equipment.json` 保存资源路径、挂点、局部变换和校准依据，`Script/Equipment.as` 是生成的 AS 配装表。

哥布林弓手使用独立弓网格的固定握持姿态，跟随左手。此次只接装备外观，保留当前角色动作，没有新增拉弦、双手 IK 或装备属性系统。

`Tools/Verify-Equipment.ps1` 逐帧求值 15 种模型的待机、跑动、攻击、受击和死亡动作，共 75 个动作条件、85 个装备/动作组合。校验实际骨骼与部件世界变换、校准握持点、父组件、挂点以及关闭碰撞；同时检查片段时间范围和真实手骨运动，避免只验证静止姿态。结果见 `equipment-analysis.json`。

100 人编辑器场景已保存并重新加载核验，记录见 `equipment-map.json`。离线重新生成配装并更新场景使用 `Tools/build_equipped_map.py`；读取资产与依赖使用 `Tools/audit_equipment.py`。运行期间装备由 AS 的 `EquipVisuals()` 挂载，死亡和复活保持同一套配装。

最终校验通过 4929 个采样点，挂载位置误差最大为 0 cm，骨骼校准握持点误差最大为 0.000025 cm。这是参考点的变换误差；实际外观同时通过弓、剑盾与太刀的冻结姿态截图检查，见 `Proof/equipment-goblin-bow.png`、`Proof/equipment-shield.png`、`Proof/equipment-samurai-final.png`。

[带装备的 100 人混战录像](Recordings/equipment/capture-729def498ab54e1b840576c22cdebfb5/recording.mp4)：约 25 秒、1600×1000，实际捕获 14.90 FPS；374 帧全部解码通过且非黑。仅捕获本 3C 实验窗口。最终运行日志确认 100 个单位已完成装备初始化，没有 AS 编译错误或装备加载错误。
