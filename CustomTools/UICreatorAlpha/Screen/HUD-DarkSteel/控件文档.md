# HUD · 暗钢快捷栏

此目录保留最初 688×170 裁切图的参考快照。已保存工程的场景入口已扩展为完整 RuleStudio 战斗 HUD；其组件与交互约定见 `../RuleStudio-HUD/控件文档.md`。截图中的第四槽选中属于参考快照，不是完整 HUD 的默认游戏状态。

参考：用户提供的 688×170 截图。主 HUD 设计画布为 1600×900，快捷栏保留原生 688×170 协议，经 ScaleBox 等比放大，底部边距 20，始终水平居中。

## 预制体层级

```text
HUD 场景
└─ HUD · 暗钢（界面预制体）
   └─ 底部中央 · 等比适应
      └─ 暗钢快捷栏 · 参考尺寸（界面预制体）
         ├─ 内层暗板
         ├─ 参考折面与装饰（独立可隐藏的上下文层）
         ├─ 技能栏 · 1–4（组合预制体）
         │  └─ 技能槽 · 四态 ×4（原子预制体）
         │     ├─ Normal / Hover / Pressed / Disabled SVG
         │     ├─ 快捷键（独立文字）
         │     ├─ 技能图标（烈字路径 SVG）/ 空槽加号 SVG
         │     ├─ 名称、装备标记（独立文字）
         │     └─ 选中青色描边（独立透明 SVG）
         ├─ 消耗品栏 · Q E F G（组合预制体）
         │  └─ 快捷键槽 · 四态 ×4（原子预制体）
         └─ 操作提示（独立文字）
```

6 个预制体，8 个实际按钮。快捷键、图标和文字不进入按钮背景资产。第四个技能槽默认选中；第一槽包含烈焰爆发图标及装备标记；其他三个技能槽为空槽。

## SVG 资产分类

在编辑器 SVG 资产库中打开 `HUD · 暗钢快捷栏`：

| 子文件夹 | 内容 | 数量 |
| --- | --- | --- |
| 底座折面 | 左侧折面、右侧折面、内层暗板 | 3 |
| 技能槽与状态 | 已装备四态、空槽四态、独立选中描边 | 9 |
| 快捷键槽与状态 | 消耗品槽四态 | 4 |
| 图标与符号 | 半环、金色定位点、加号、烈字矢量图标 | 4 |

原始 SVG 文件位于 `src/assets/hud-darksteel/svg/`。资产的路径、尺寸及哈希记录在 `composition.json`，工程交换文件为 `hud.uialpha.json`。保存到编辑器后 SVG 和预制体分别持久化，由工程清单引用。

“烈”字图标采用本机 Microsoft YaHei Bold 的单字轮廓转为 SVG path；没有嵌入字体文件或位图。槽位的十二个状态资产使用九宫格缩放，选中辉光单独保留透明边距。底座折面作为参考上下文独立管理，可在预览中关闭。

## 打开与验证

- 编辑器：`http://127.0.0.1:5188/?project=hud-darksteel-20261024`

当前为 SVG 重建，不宣称与参考逐像素完全一致。字体栅格、辉光和少量折面边缘存在绘制差异。未操作 UE。
