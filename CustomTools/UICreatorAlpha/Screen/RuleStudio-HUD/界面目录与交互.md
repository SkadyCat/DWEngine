## 数据与交互

- 角色属性和特性独立滚动；滚动区域具有按真实内容范围计算的滚动条。
- 搜索使用临时原生输入框支持中文输入法；提交后由 SVG 文本绘制。保存的界面没有 foreignObject。
- 装备替换只影响对应槽；未鉴定装备不可直接装备。详情使用当前物品名称、图标、品质和词条。
- 右键菜单跟随当前物品，单件物品禁用拆分。拆分校验整数范围并保持总数量不变。
- Hunter 的查询、已选词条、仅看已选、分页与通货过滤分别保存。
- 购买扣除预览钱包并加入预览背包，每个商品限购一次。定价只作用于本次预览。
- 洗炼预览维护每件装备的选定记录，最多三条；消耗通货，展示更新后的词条。
- 星图为 1040×660 的居中窗口，复用角色页的金色标题栏、深蓝灰底和细边框。地图路线、标记和节点皮肤均为独立 SVG 资产；可拖动平移、滚轮或按钮缩放，F 复位。选中边框独立于悬停；未连通地域可查看详情、禁止进入。窗口在小视口下保留 16px 边距并等比缩小，拖动按缩放后的点击区域换算坐标。
- 原有快捷栏逻辑保持：唯一选中槽、点击打开 / 关闭装配、数字键只切槽、技能移动后原槽留空、空槽禁用清空。

这些是可替换的数据契约与 UI 交互样例。装备数值、词条池、商店库存和星图节点是有限的预览数据，不复刻 RuleStudio 的战斗、随机掉落、经济或洗炼规则引擎。图标为原素材转换的 SVG 路径，地形为原生 SVG 重绘；矢量化结果不保证与原 PNG 像素一致。

## 物品悬停详情

背包物品、角色背包格子与已穿戴装备槽共用 `battle-prefab-item-hover`。悬停或键盘聚焦立即显示当前物品的图标、品质、数量、说明与词条；未鉴定装备隐藏属性，空格不显示详情。悬停不修改背包选中项；Ctrl 固定后，其他物品的悬停不会替换内容。固定面板可查看完整详情、装备 / 卸下、洗炼 / 鉴定；Esc 或 × 仅关闭详情，保留背包。

浮层由同一 SVG 运行时渲染，放在滚动裁剪区域之外，按浏览器可见范围翻转、限位及缩小。非固定浮层不拦截鼠标，移开、滚动、拖动时关闭；切换界面或停止预览会销毁浮层及其监听。模板归类于“3D 战斗界面 / 共享控件”，可通过 `node scripts/update-battle-suite.mjs --item-tooltip-only --save` 单独更新。

## 结构

- `src/assets/rulestudio-hud/suite-art.js`：原生矢量资产生成；磁盘 SVG 位于 `svg/suite/`。
- `suite-kit.js`：控件、Slot、状态皮肤和窗口构造。
- `suite-data.js`：预览数据。
- `suite-pages.js`：界面和嵌套控件预制体。
- `atlas.js`：星图窗口布局、地域连接、节点状态和地图 SVG；通过 `node scripts/update-battle-suite.mjs --atlas-only --save` 单独更新，保留其他页面与共享皮肤的修改。
- `suite.js`：安装目录、资产与兼容引用。
- `src/runtime/battle-suite-state.js`：临时数据状态。
- `src/runtime/battle-suite.js`：输入、导航、动态列表和视图投影。
- `item-tooltip.js` / `runtime/item-inspector.js`：持久化的悬停详情预制体、独立 SVG 浮层和指针 / 焦点 / Ctrl 固定逻辑。浮层只收集自身引用的 SVG，复用当前视图音频播放器。
- `interfaceCatalog`：稳定 ID 指向预制体。目录与模板在保存、导入及再次加载时共同验证。

主 HUD 未打开的窗口不展开。常规 HUD 实际排列 187 个节点；完整源展开 272 个节点。窗口通过 `setChildren` 挂载选中的预制体；所有派生状态都不修改源模板。旧窗口预制体 ID 通过实例兼容引用新模板。
