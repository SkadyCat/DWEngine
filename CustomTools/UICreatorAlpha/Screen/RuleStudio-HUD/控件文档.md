# RuleStudio · 完整战斗 HUD

参考本机 `G:/DungeonWorldBeta/CustomTools/RuleStudio/public/battle3d.mjs`、`play.css`、`battle-functions.mjs`、`battle-character-panel.mjs` 和 `engine/loadout.mjs`。这是 SVG 界面及交互预览，不连接战斗引擎或 UE。场景画布 1600×900。

已保存为工程 `hud-darksteel-20261024`。旧的 688×170 截图重建预制体仍保留为参考资产；场景入口现在是完整战斗 HUD。3D 地面、角色和场景折面属于世界渲染，不放进 HUD。

## 组件

- 左上：气血、护盾、魔力进度条；层数、波次；首领气血；召唤单位；可展开 BD；重置。
- 顶部：灵石、击杀、怪物、投射物、时间及 FPS。
- 右上：单体秒伤、小地图、地图装备词条与谱系页签。
- 右侧：背包、属性、技能、装备、消耗品、BD、Hunter、地图、谱系、设置、商店、洗炼，共 12 个独立图标按钮。
- 底部：4 个稳定技能槽，Q/E/F/G 消耗品槽和操作提示。
- 窗口：6×12 背包、属性与装备、配装、Hunter、战场设置、商店、洗炼、详情、通关、失败；另有技能装配浮层。

工程现含 31 个界面 / 状态、159 个独立 SVG 资产、58 个预制体。最新覆盖与入口见 [界面目录与交互](界面目录与交互.md)。常规 HUD 仅排列当前可见组件，窗口关闭时不排列其后代。SVG 和预制体均在“战斗 HUD”文件夹下分类。

## 选中约定

1. `selected` 是唯一当前槽索引，`picker` 是装配面板目标，`skills` 是四个固定位置的数据，三者分别保存。
2. 点击技能槽会选中该槽并打开装配面板；再次点击同槽关闭面板。数字键 1–4 只切槽并关闭装配面板。
3. 空槽可选中，内容仍为加号和“空槽”。选择不会把技能复制到其他槽。
4. 装配已在其他槽中的技能时，移到目标槽，原位置留空；清空一个槽不会让其他槽前移。
5. “装备”是 `granted` 来源标记。它与鼠标悬停、当前选中和按钮按下状态无关。
6. Normal/Hover/Pressed/Disabled 是按钮皮肤；Hover 和 Pressed 为灰色边框。唯一青色选中框是单独的透明 SVG 图层。
7. 嵌套预制体的 `action` 在展开时深拷贝，避免多个实例共用槽位索引。批量运行时更新先完整校验，再统一重排一次；不写回源工程。
8. `presentation.skills` 是技能目录，`availableSkills` 是已拥有或装备授予的可装配集合。目录中的其他技能不会出现在弹窗中。当前参考样例为毒瓶在第一槽、其余三槽为空，弹窗只有一条毒瓶。
9. 条目由“技能装配条目”预制体动态生成，包含图标、名称、来源和状态。当前槽显示“当前槽位 / 已装配”；其他槽显示“从槽 N 移入”；未装配时只显示来源。空槽禁用“清空此槽”。
10. 单条列表的面板为 314×144；多条自动增高，最高 280 后滚动。点击外部或 Esc 关闭；打开时焦点进入条目，关闭后返回当前技能槽。已有技能的青框为实线，空槽为虚线。

## 编辑与预览

打开 `http://127.0.0.1:5188/?project=hud-darksteel-20261024`。

直接对照毒瓶弹窗：`http://127.0.0.1:5188/?project=hud-darksteel-20261024&preview=skills&focus=hotbar`。此链接自动进入预览、打开当前槽装配列表并以原始尺寸聚焦快捷栏，不改变保存的画布和布局。

点右上“预览”，可直接点击各功能按钮；B 打开背包，C 打开属性，Esc 先关闭面板，再退出预览。工具栏“HUD 界面状态”可切换常规、首领、背包、属性、装配、Hunter、设置、通关、失败等视图。退出预览恢复设计内容；运行时装配不改变工程文件。

在预制体库打开 `战斗 HUD / 窗口与状态界面`，点击对应预制体的“编辑 ↗”可独立编辑窗口；主界面在 `战斗 HUD / HUD 组件`。文字、图标、背景、状态及布局均为独立节点。
